# Delírios — Atlética de Biomedicina do UNIARAXÁ

Primeira proposta de site institucional com agenda e prévia de coleção. Site estático na raiz do projeto, sem dependências de build.

## Executar localmente

```sh
node server.mjs
```

Acesse http://localhost:4173.

## Direção visual

- Vinho `#420D20`: cor de marca; vinho profundo `#23070E`: fundos.
- Dourado `#DBB767`: chamadas e destaques.
- Preto `#100E0F`: agenda e rodapé.
- Vermelho `#BF263D`: faixa e acentos.
- Marfim `#F2EEE5`: leitura e contraste.
- Barlow Condensed para títulos; DM Sans para corpo (Google Fonts, com fallback local).

## Conteúdo e limites desta versão

Instituição e curso fornecidos pelo usuário. Artes originais copiadas sem edição. A arte do escudo diz “Delírio”; o site usa “Delírios”, conforme solicitado. Confirmar nome final antes de lançamento público.

Agenda sem eventos fictícios. Os três produtos são propostas ilustrativas explicitamente identificadas, não itens reais disponíveis. Não há checkout, pagamento, estoque, envio de formulários nem coleta de dados. O convite para participar informa que contatos ainda serão divulgados.

Para ativar os fluxos comerciais: receber catálogo, fotos finais, preços, tamanhos, estoque, retirada/entrega, canal de atendimento e meio de pagamento; depois integrar pedidos e pagamentos. Para agenda: datas, locais, valores e links oficiais. Para participação: contato e processo de associação.
